## Alt Klasörler

- `archive/` — tek seferlik fix notları, bug raporları, eski migration check-in'leri (~57 dosya). Referans için tutulur, aktif çalışma değildir.
- `specs/` — feature spec'leri (`.kiro/specs` kopyası): archive-view-system, circle-gradient-backgrounds, design-system-tokens, instagram-story-cards, personalized-song-recommendations.
- `design/` — marka ve tasarım dokümanları: `ONE_AppStore_Pitch.md`, `ONE_UX_Wireframe.md`, logo ve color rehberleri.
- `marketing/` — ASO günlük raporları, Instagram içerik takvimi, sosyal medya kit.

## Tooling

`../tooling/` altında repo yardımcı scriptleri ve veri dökümleri: dashboard (Python + HTML), CloudKit veri JSON'ları, typography migration scripti, test plan.
