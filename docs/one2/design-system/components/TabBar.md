# TabBar

Yüzen cam alt gezinme ve üstünde yüzen + butonu.

- 5 sekme: Bugün · Sözler · Keşfet · Yolculuk · Eğilimler. İkon + 12pt etiket, hepsi `ink`; seçili sekme `ground` hap içinde.
- Zemin `glass` (iOS: `.ultraThinMaterial` + tint), 1px `line` iç kenar, `shadow-float`; kenarlardan `space-4`.
- + butonu: tab bar ortasının üstünde, 72×56 `primary` hap. Boş sayfa, Mood check-in, Günlük önerisi, Şablonlar, Kütüphane sheet'ini açar.
- Profil Bugün'ün sağ üstünde.

Tüketici sağlar: seçili sekme, sekme değişimi, + eylemi.
