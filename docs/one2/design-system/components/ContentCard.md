# ContentCard

Keşfet ve Kütüphane içerik karosu: rehberli günlük, egzersiz, tema.

- Üstü yuvarlak kemer biçimli 88pt görsel; kilitliyse ortada kilit; altına taşan mono rozet ("YENİ", "ÖNE ÇIKAN") `ground` zeminde.
- Kemer rengi türü söyler: akşam içerikleri `aksam`, sabah içerikleri `sabah`, diğerleri `raised`.
- Kategori (`callout`, `ink-muted`), başlık (700 20), 2 satır açıklama; sağ üstte "···" menü.

Tüketici sağlar: tür, kategori, başlık, açıklama, kilit, rozet.
