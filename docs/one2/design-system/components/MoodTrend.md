# MoodTrend

Eğilimler kartları: mood çizgisi ve duygu dağılımı.

- `surface` `radius-lg`; başlık 700 20, alt satır `ink-muted`, sağ üstte mono özet ("ORT 3,5").
- Mood çizgisi: 1–5 mono eksen, `line` ızgara, `ink-muted` çizgi; noktalar `score-N` dolgu + `ground` halka; bugün büyük ve `ink` halkalı.
- Duygu dağılımı: yatay çubuklar, `emo-*` dolgu, `raised` ray, mono yüzde.
- Üstte `label` "GENEL İÇGÖRÜLER"; veri yoksa `States` içindeki boş check-in kartı.

Tüketici sağlar: (tarih, skor) dizisi, duygu yüzdeleri, dönem.
