# JournalEditor

Yazma ekranı: tam ekran, `ground` zemin, dikkat dağıtan öğe yok.

- Üstte mono bağlam etiketi ve "Bitti"; soru `prompt` (serif 22) `ink`; kullanıcı metni `journal` (serif 18/29).
- Alt araç hapı (`raised`): Biçim, Foto, Ses, Şarkı, Etiket + mono kelime sayısı; klavyenin üstüne yapışır.
- Otomatik kayıt. "Bitti" → `Seal`.

Tüketici sağlar: soru, metin, ekler, kayıt.
