# Button

Hap butonlar; renk değil kontrast taşır.

- **primary**: açık hap (`primary`) + koyu metin (`on-primary`). Ekran başına bir: "Yaz", "Başla", "Günü kapat".
- **secondary**: `raised` + `ink`.
- **text**: `ink-muted`, dolgusuz.
- **danger**: `danger` metin; onay sheet'i açar.
- 52pt yükseklik (kart içinde 48), `radius-pill`, basışta `scale(0.97)`.

Tüketici sağlar: 1–3 kelimelik fiil, isteğe bağlı SF Symbol, eylem.
