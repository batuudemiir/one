# States

Her ekranın ek durumları.

- **Çevrimdışı**: `raised` hap şerit, `warning` ikon + tek cümle.
- **Yükleniyor**: `raised` iskelet çubukları, spinner yok.
- **Boş**: 1px `line` çerçeveli kart, başlık + tek cümle + tek eylem (Eğilimler'de doğrudan `ScoreScale`).
- **Hata**: `danger` kelime + ne yapılacağı.
