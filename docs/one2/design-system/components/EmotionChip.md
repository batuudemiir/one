# EmotionChip

Check-in'in ikinci adımı: duyguları çoklu seçtirir; her duygu 8 aileden birine aittir.

- Seçilmemiş: `raised` hap + 10px aile noktası (`emo-*`).
- Seçili: aile dolgusu + `on-emo-*` metin.
- Aile sınıfları `e-nese` … `e-yorgun`.

Tüketici sağlar: duygu listesi (id, ad, aile), seçim, geri çağrı.
