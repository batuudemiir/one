# PracticeTile

- `surface`, `radius-lg`, 2 sütun; ortada 72pt `raised` yuvarlak ikon kuyusu, altında ad (`headline`).
- Bölüm başlığı "Pratiklerin" (`title`) + sağda düzenle (sliders) ikonu.
- Son karo "+ Ekle": şeffaf zemin, 1px `line`.
- Uzun basma: sırala / kaldır.

Tüketici sağlar: ad, SF Symbol, eylem.
