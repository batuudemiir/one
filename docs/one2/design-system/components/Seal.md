# Seal

Ritüel bitince sakin kapanış: mühür, tek cümle, dolan hafta.

- 96pt `brand` disk + tik, dışında `ground` boşluk ve ince `brand` halka.
- Başlık küçük harf (700 30), altında serif italik özet.
- Altında `WeekStrip`; bugünün hücresi bu anda tike döner.
- Hareket: disk 0.9 → 1.0 + opaklık, 320ms, tek sefer; `.soft` haptik. Konfeti, ses, "Harika!" yok.

Tüketici sağlar: cümle, özet, hafta durumu.
