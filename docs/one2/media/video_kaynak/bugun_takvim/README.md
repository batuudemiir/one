# ONE 2.0 — Bugün, takvim ve yeni girdi (kısa, TR + EN)

`../../one2_bugun_takvim_tr.mp4` (Türkçe) ve `../../one2_today_calendar_en.mp4` (İngilizce):
1080×1920, 30 fps, 29 sn. Piksel şehir teması, akşamdan geceye. Tek kaynak; dil `?lang=tr`.

Akış:
1. Bugün (UX-4, `ScreenBugun`): seri hapı, selamlama, hafta şeridi (Çar boş, Per bugün),
   check-in kartı + yankı, Pratiklerin, Haftalık tema; aşağı kaydırma.
2. Yolculuk (UX-9): Günler görünümü → dönem hapı → Aylar → Eylül 2026 takvimi
   (gün hücresinde skor rengi, yazı işareti, bugün çerçeveli).
3. Yüzen + → Plus sheet (UX-3: Boş sayfa, Mood check-in, Günlük önerisi, Şablonlar, Kütüphane)
   → Boş sayfa → editör (UX-6) → Bitti → "Bugün kapandı." + hafta şeridinde bugün tike döner.
4. Takvimde 24 Eylül dolar → kapanış kartı.

Tarihler gerçek takvime göre: 1 Eylül 2026 Salı, 24 Eylül Perşembe.
